# Лабораторная работа №3. Вёрстка макета с помощью Flexbox и Grid
## Задание
Дополнить макет страницы:
- Flexbox: навигационное меню (горизонтальное, адаптивное) и карточки (3–4 шт.) в
ряд.
- Grid: галерея/дашборд (2–3 колонки, 2–3 строки).
- Медиа-запросы для планшетов и мобильных; отсутствие горизонтальной прокрутки.
- Контрастность ≥ 4.5:1; семантически верные теги для карточек.

**Вариант 14. Тема «Дизайнер и визуализатор» (стили и палитры)** Flex-карточки: «Стили в дизайне» (превью, название, краткая характеристика). Grid-галерея: «Палитры недели» (4 цветовых блока + название палитры сетка 2×2 или 2×3). Адаптивность: карточки – 1/2/3; Grid – на мобильном 1 колонка, на остальных 2. Используйте CSS-переменные для цветов палитры и выводите их значения текстом в блоках.
**Инструменты:** HTML/CSS, мобильные эмуляторы в DevTools.

**Критерии:**
- Flexbox реализован корректно.
- Grid реализован корректно.
- Адаптивность работает на всех устройствах.
- Медиа-запросы присутствуют и работают.
- Соблюдены требования доступности.
